# His Recoveries — オフライン・マーケティング戦略

> 街中QR / 匿名BOX を起点に、最初の100件の改善レビューと最初の1,000人を獲得する。
> 「恥の悩み」はオンライン広告では獲れない。物理空間でしか開かない財布と口がある。

最終更新: 2026-06 / 対象フェーズ: 0→1（最初の100レビュー獲得）

---

## 0. このドキュメントの目的

His Recoveries は「男性コンプレックスの改善体験データベース（男性版RealSelf）」。
検索エンジンなのに**データが無ければ価値ゼロ**＝コールドスタート問題が最大の急所。

この資料は、その急所を**オフライン起点**で突破するための戦略をまとめる。

- **狙うKPI**: 最初の100件の質の高い改善レビュー / 最初の1,000スキャン
- **収益の本体**: B2B送客（AGA・ED・包茎・多汗症・体臭クリニック、送客単価 約3万円）
- **試算**: 送客3万円 × 年3,300件 ≒ 年商1億円（月275件 / 月間数万PVで到達圏）

---

## 1. なぜ「オフライン × 匿名」なのか（中心仮説）

恥の悩みには、オンライン獲得を阻む3つの壁がある。

1. **検索しても広告と嘘の成功談しか出ない** → 不信
2. **SNSでは絶対に共有されない**（友達に言えない）→ バズらない
3. **広告を踏んでも「申し込む」勇気が出ない** → CVしない

一方、**「一人になれる物理空間」**には、ガードが下りた瞬間がある。
鏡の前・更衣室・トイレ個室・クリニック待合 — そこに置いた**匿名BOX/QR**は、
「誰にも言えないこと」を初めて吐き出させる装置になりうる。

> 公開では書けない。でも、誰も見ていない箱には書ける。

これは NGL（匿名×ホスト経由で2.5億DL）の「匿名なら開く」原理を、
オンラインではなく**物理空間**に適用するもの。

## 2. 配置戦略 — 「どこに置くか」が成否の9割

不特定多数の街中ではなく、**“すでに悩んでいる男性が、ひとりで居る場所”**に置く。

### Tier 1（最優先・高純度）
| 場所 | 刺さる悩み | 理由 |
|---|---|---|
| AGA / 美容皮膚科 / 泌尿器科の**待合・トイレ** | AGA・ED・包茎・多汗 | 既に悩んで来院＝最高純度。提携で送客も同時に握れる |
| **理容室・メンズサロンの鏡前** | 薄毛・ヒゲ・肌 | 自分の頭・顔を直視する瞬間 |
| **ジムの更衣室・シャワー・体組成計の横** | 体型・体臭・薄毛 | 身体を意識し無防備になる空間 |

### Tier 2（一人になれる空間）
| 場所 | 刺さる悩み |
|---|---|
| **銭湯・サウナの脱衣所** | 体臭・包茎・体型 |
| 大学・専門学校のトイレ個室 | 若年層の全般 |
| ネットカフェ個室・カプセルホテル | ED・全般 |

### Tier 3（面で撒く・補助）
- メンズ美容のフリーペーパー / クリニックの会計時カード同梱
- 大学サークル・寮の掲示板

> 原則: **「人目が無い」×「悩みを思い出す」**が重なる場所を最優先。

## 3. 物理クリエイティブ（QRポスター / BOX）

実装済み: `/poster`（A4印刷可・QR自動生成・URL編集可）

### デザイン原則
- 黒地・余白・極小文字。**広告に見せない**（Aesop / 余白の美学）
- 説明しすぎない。**問いだけを置く**

### コピー（A/Bテスト用バリアント）
**メイン（汎用）**
> 誰にも言えないことを、ここへ。
> 匿名・登録なし・30秒

**場所特化**
- 理容室/ジム: 「鏡の前で、本当は何を思ってる？」
- クリニック待合: 「その悩み、ひとりじゃない。」
- トイレ個室/銭湯: 「ここでは、誰も見ていない。」

**安心の担保（小さく必ず入れる）**
> 名前も連絡先も要りません。書いたものは誰にも紐づきません。

### BOX版（物理投函）
- QRに加え、**紙とペンで物理投函**できる箱を併設すると、デジタルが苦手な層・より深い告白を拾える
- 回収した手書きは、本人が特定されない形で**症例の種**に（要同意文の掲示）

## 4. 獲得ファネル（QR → 製品）

```
[街中QR / BOX]
   ↓ スキャン
/confess  「誰にも言えないこと、ありますか？」
   ↓ 匿名で吐き出す（30秒）
「ありがとう。あなただけじゃない」
   ↓ 同じ悩みの仲間 ◯人
/cases?c=<悩み>  似た人の改善事例（悩みで絞込済み）★鏡の瞬間
   ↓ 集合知（やってよかった率・費用中央値・施術）
   ↓ 一部は Give to Get でロック
[投稿で解放] → 改善レビューが1件増える（=供給）
   ↓
[改善手段→提携クリニック→予約]（送客＝収益）
```

入口カテゴリは製品と統一済み: **AGA / ED / 包茎 / 多汗症 / 体臭**

## 5. 計測設計（どの場所が効いたかを必ず測る）

各設置場所に**固有QR**を発行し、URLにソースを付ける。

```
https://shokunin-neon.vercel.app/confess?src=gym-shibuya-01
https://shokunin-neon.vercel.app/confess?src=clinic-shinjuku-02
```

- `src` を投稿データに保存 → **場所別のスキャン数・投稿率・送客率**を比較
- 勝ち場所に資源集中、負け場所は撤去（Strava型: 効くものに張る）

**追うKPI（PVではない）**
1. スキャン数（場所別）
2. スキャン→投稿率（恥を開けたか）
3. 投稿→事例閲覧率
4. 事例閲覧→Give to Get投稿率（データ増殖）
5. 送客クリック / 予約数（収益先行指標）

> ※ `?src=` の保存はアプリ側に未実装。次の開発タスク候補。

## 6. 提携戦略（クリニック / サロン）= 収益と供給の同時獲得

Tier 1 への設置は「広告」ではなく**Win-Winの提携**として持ちかける。

**先方のメリット**
- 待合のQRから、自院に**質の高い見込み客が戻ってくる**送客
- 「改善事例DBに掲載される」ことのブランド露出（将来）

**こちらのメリット**
- 最高純度の悩みデータと、最初のレビュー投稿者
- 送客フィー（Phase2以降の収益）

**進め方**
1. まず1〜2院でパイロット（設置＋送客レポートを手で作る）
2. 「月◯件送客しました」の実績を持って横展開

## 7. 法的・倫理ガードレール（必読）

- **医療広告ガイドライン**: クリニックの広告として体験談/Before-Afterを出すのはNG。
  当社は**第三者UGCプラットフォーム**として本人の実体験を扱う（土俵が違う）。
  Before/Afterは**費用・期間・リスクを必ず併記**。
- **ステマ規制（景表法）**: 投稿の見返りに**報酬・割引は厳禁**（2024年 消費者庁 措置命令の実例あり）。
  インセンティブ型キャンペーンは行わない。
- **名誉毀損**: クリニック名を出す投稿は事実ベース・本人体験のみ・モデレーション必須。
- **設置許可**: 私有地（クリニック・ジム・店舗）は必ず**事前許可**。公共空間への無断掲示はしない。
- **プライバシー**: 匿名・無登録を徹底。手書きBOXは「症例化への同意」を掲示。
- 表現は「治る/完治」を避け「改善/変化/記録」を使う。

## 8. ロールアウト計画

### Phase 0｜パイロット（〜1ヶ月）
- 提携1〜2院 ＋ 理容室/ジム 2〜3箇所に固有QRで設置
- 目標: **100スキャン / 最初の30レビュー**
- 創業者が手で症例を構造化・取材も並行

### Phase 1｜検証（〜3ヶ月）
- 勝ち場所を特定し10〜20箇所へ
- 目標: **1,000スキャン / 100レビュー / 送客パイロット開始**
- 1ジャンル（AGA か 包茎）を50件まで深掘りして制覇

### Phase 2｜拡大
- 送客実績を武器にクリニック提携を面で拡大
- フリーペーパー等の面展開を追加

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 設置しても誰も書かない | 場所のTier見直し / コピーA/B / BOX併設で物理投函 |
| 投稿が集まっても質が低い | 構造化フォーム＋検証バッジ＋手動モデレーション |
| クリニックが提携に乗らない | まず送客実績を1件作ってから交渉 |
| 法規制（医療広告/ステマ） | 第三者UGC設計・無報酬・併記徹底（§7） |
| いたずら/誹謗中傷投稿 | モデレーション・公開前審査 |
