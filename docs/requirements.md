# SHOKUNIN 要求定義書

## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | SHOKUNIN（職人） |
| コンセプト | 職人の技術を、正当に評価する |
| 種別 | 職人特化型スキルシェアプラットフォーム |
| ターゲット市場 | 日本国内の建築・設備系職人と一般消費者 |

### 1.1 解決する課題

- **職人側**: 中間業者に利益を搾取され、技術が正当に評価されない
- **消費者側**: 信頼できる職人を見つける手段が限られている
- **業界全体**: 技術の継承が困難で、若手育成の仕組みがない

### 1.2 提供価値

- 職人と消費者を直接つなぎ、中間マージンを排除
- AI を活用したプロフェッショナルな出品支援
- 動画コースによる技術継承プラットフォーム
- 位置情報に基づく最適な職人マッチング

### 1.3 ファウンダーの独自性と競合優位

#### 背景
ファウンダーはセーフィーフィールドワークス（建設・設備現場向け映像SaaSプラットフォーム）での営業経験を持つ。建設・設備業界の現場に日常的に入り、職人の働き方・技術伝承の現実・業界の構造的課題を一次情報として把握している。

#### 「くらしのマーケット」「ミツモア」との決定的な違い

既存競合は「消費者が業者を探す」マッチングに留まっている。SHOKUNINは以下の2軸で本質的に異なる:

**1. 職人の技術を可視化する**
- 施工の「腕」は文章だけでは伝わらない。現場映像・施工写真・Before/Afterを体系的に蓄積し、職人の技術力を証明可能にする
- セーフィーでの現場映像活用の知見を応用し、「技術の見える化」を仕組みとして構築
- 消費者は「安い業者」ではなく「確かな腕を持つ職人」を選べるようになる

**2. 職人になるための教育システムを内蔵する**
- 競合はマッチング止まり。SHOKUNINは「技術を学ぶ→職人になる→仕事を受ける」のライフサイクル全体をカバー
- 熟練職人の技術を動画コースとして体系化し、若手育成のインフラになる
- 「教える側の職人」に新たな収入源を提供しつつ、業界全体の技術水準を底上げ

#### この2つが組み合わさることで生まれる価値

```
[学ぶ] 動画コースで技術を習得
   ↓
[証明する] 施工実績・映像で腕を可視化
   ↓
[選ばれる] 技術で正当に評価され、仕事を獲得
   ↓
[教える] 熟練後、自分もコースを作成して次世代へ継承
```

これは「マッチングサイト」ではなく、**職人のキャリアプラットフォーム**である。
既存競合が「今いる業者を探す」だけなのに対し、SHOKUNINは「職人を育て、評価し、つなぐ」エコシステムを構築する。

## 3. 機能要求

### 3.1 職人検索・マッチング

```
入力: 郵便番号 + 職種フィルタ（任意）+ 検索半径（デフォルト50km）
処理: PostGIS地理空間検索（ST_DWithin）
出力: 距離順にソートされた職人リスト（名前・職種・評価・距離）
```

- 郵便番号 → 住所変換: zipcloud API
- 住所 → 座標変換: **現在はダミー座標（要改善：Google Geocoding API等）**
- 検索方式: 円形半径検索（PostGIS GIST インデックス）

### 3.2 施工パッケージ管理

- **CRUD操作**: 作成・一覧取得（カテゴリフィルタ対応）
- **カテゴリ**: エアコン設置 / 電気工事 / 水道工事 / 内装工事 / 外壁塗装 / リフォーム
- **AI出品支援**: 職人が口語入力 → Claude API がプロ仕様の説明文・HTML・タグ・Schema.org JSON-LD を生成
- **SEO**: Schema.org 構造化データを各パッケージに付与

### 3.3 決済・注文管理

```
注文ライフサイクル:
pending → authorized → scheduled → in_progress → completed → invoiced → paid
                                                                        ↘ cancelled
```

- **2段階決済**: Stripe PaymentIntent（manual capture）
  - 予約時: 与信枠確保（authorize）
  - 施工完了時: 実売上計上（capture）
- **完了報告**: 施工写真アップロード → Supabase Storage
- **請求書**: n8n Webhook 経由で自動生成
- **Webhook**: Stripe イベント（succeeded / failed）を処理

### 3.4 動画学習プラットフォーム

- **コース構成**: コース → チャプター（複数、順序付き）
- **動画配信**: Supabase Storage + 署名付きURL（60分有効）
- **アクセス制御**: 購入者 or コース作成者のみ視聴可能
- **進捗管理**: チャプター単位の視聴秒数・完了フラグ / コース全体の完了率
- **購入**: Stripe 決済 → Webhook で `course_purchases` に記録

### 3.5 認証・認可

- **認証**: Supabase Auth（Cookie ベースセッション）
- **RLS（Row Level Security）**: 全テーブルに適用
  - 公開データ: 誰でも閲覧可（職人プロフィール、アクティブなパッケージ、公開コース）
  - 個人データ: 本人のみ（注文、学習進捗、購入履歴）
  - 管理データ: 該当職人のみ（自分のパッケージ・コース編集）

| 項目 | 要求値 |
