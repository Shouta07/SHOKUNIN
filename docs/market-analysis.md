## 3. 外部環境 — 今何が起きているか

### 3.1 人手不足（深刻）

| 指標 | 数値 |
|------|------|
| 建設業就業者数 | 477万人（ピーク比 ▲30%） |
| 有効求人倍率（建設技術者） | **4.93倍**（全産業平均1.24倍の4倍） |
| 躯体工事の求人倍率 | **7.65倍** |
| 55歳以上の割合 | **36.6%** |
| 29歳以下の割合 | **11.6%** |
| 人手不足倒産（2025年上半期） | 建設業113件（全産業の29%、過去最多） |

### 3.2 法規制の変化

| 時期 | 制度 | 影響 |
|------|------|------|
| 2024年4月〜 | **2024年問題**（残業上限規制） | 月45h/年360hが上限。日給制の職人は収入減 |
| 2023年10月〜 | **インボイス制度** | 一人親方が課税事業者か排除かの選択を迫られる。2029年に経過措置終了 |
| 2024年1月〜 | **電子帳簿保存法** | 請求書・領収書の電子保存が義務化 |
| 進行中 | **CCUS**（建設キャリアアップシステム） | 技能者170万人登録。公共工事で実質義務化が進行中 |
| **2027年4月** | **育成就労制度** | 技能実習を廃止。2年後に転籍可能。最大123万人受入想定 |

### 3.3 成長市場

| 市場 | 2024年 | 2030年予測 | 成長率 |
|------|--------|-----------|--------|
| 建設DX市場 | 586億円 | 1,250億円 | **+113%** |
| 建設テック全体 | 1,845億円 | 3,042億円 | **+65%** |
| 建設投資額 | - | 2026年度 79.2兆円 | +5.0%/年 |

### 3.4 注目トレンド

- **i-Construction 2.0**: 2040年までに現場省人化3割・生産性1.5倍が国の目標
- **BIM義務化**: 公共事業で義務化済。2026年春から図面審査制度開始
- **AI活用の実用化**: 安全管理カメラ、施工計画自動生成、書類ドラフト
- **国土強靭化**: 2026年度から中期計画始動。2030年まで20兆円規模

```
           建設特化        汎用

```

### 4.2 狙い目は3つ

#### ① 建設人材会社向け業務管理SaaS 【最もおすすめ】

```
なぜ空白？ → 汎用ツール（スタッフナビ・kintone）はあるが建設特化がない
なぜ今？  → 2024年問題で労働時間管理が厳格化。CCUS連携ニーズが急増
           → 2027年の育成就労制度で外国人管理が複雑化
           → インボイス制度で一人親方の管理が変化
あなたの強み → COO代行として毎日このオペレーションをやっている
市場規模 → 建設人材派遣・紹介会社は全国に数千社
```

**追い風が3つ同時に来ている。** 2024年問題・CCUS・育成就労制度のすべてが「人材会社の管理業務を複雑にする」方向に動いている。

#### ② 建設特化 BtoC マッチング（現SHOKUNIN構想）

```
なぜ空白？ → くらしのマーケット/ミツモアは汎用型。建設特化のBtoCがない
なぜ今？  → 中間搾取の構造改革が国策。職人の直接取引ニーズが増加
リスク    → コールドスタート問題。両面市場の立ち上げが副業では厳しい
```

#### ③ クラフトバンク撤退後のBtoBマッチング

```
なぜ空白？ → 2026年4月にクラフトバンクがサービス終了。受け皿が必要
なぜ今？  → 2万社のユーザーが行き先を探している
リスク    → 助太刀が22万事業者で圧倒的。正面衝突は避けるべき
```
