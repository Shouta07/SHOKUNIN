# プロダクト候補の整理

## 前提条件

- 合同会社の事業として運営
- プラットフォーム型は避ける（連携コストが高い）
- 単機能ツールで勝負
- まず自社（建設人材会社）で使い、良ければ外販
- スキルセット: COO代行（積算・現場管理・営業）+ セーフィー営業経験

## プロダクト候補 5案

### ① 人工見積AI — 建設人材会社向け見積作成SaaS 【最有力】

```
「案件情報を入れると、人工見積書が30秒で出る」
```

| 項目 | 内容 |
|------|------|
| 解決する課題 | Excel属人化、過去見積の検索不可、粗利管理の手作業、元請フォーマット対応 |
| コア機能 | 職種別単価マスタ、人工計算、粗利シミュレーション、見積書PDF出力 |
| AI活用 | 過去実績から適正単価を提案 / 案件条件から必要人工を推定 |
| 競合 | **なし**（完全空白） |
| 自社利用 | **即日から自分がユーザー** |
| 技術流用 | Next.js + Supabase + Claude API がそのまま使える |
| 収益モデル | 月額4,980円〜（見積件数無制限） |
| 外販先 | 建設人材派遣会社（全国数千社） |
| 開発量 | MVP 3〜4画面。2〜3週間で動くものが作れる |

**なぜあなたがやるべきか:**
- COO代行として「何が面倒か」を体感している
- 積算の実務経験がある（単価感・歩掛の勘所を知っている）
- 営業経験で「元請が何を求めるか」を知っている
- 同業の知り合いに直接デモできる

### ② 施工報告AI — 現場写真→報告書自動生成

```
「写真を撮って送ると、施工報告書がPDFで出てくる」
```

| 項目 | 内容 |
|------|------|
| 解決する課題 | 毎晩1〜2時間の報告書作成作業 |
| コア機能 | 写真アップロード → AIが報告書生成 → PDF出力 |
| AI活用 | Claude Vision で写真を解析、報告書の文面を自動生成 |
| 競合 | 少ない（大手向けBIM連携はあるが、中小向けは空白） |
| 自社利用 | 派遣先の職人に使わせて検証可能 |
| 収益モデル | 月額1,980〜4,980円/ユーザー |
| 開発量 | MVP 2〜3画面。2週間で動く |

**なぜあなた:** セーフィーで「現場映像が何に使われるか」を見てきた。
**リスク:** 職人にアプリを使わせるハードルがある。

### ③ 建設営業管理CRM — 案件・元請・稼働を一元管理

```
「案件の進捗・元請との交渉・職人の稼働を一画面で把握」
```

| 項目 | 内容 |
|------|------|
| 解決する課題 | 案件情報の散在（LINE・電話・Excel）、フォロー漏れ |
| コア機能 | 案件ボード、元請管理、稼働カレンダー、対応履歴 |
| AI活用 | 案件メモから次アクションを自動提案 |
| 競合 | 汎用CRM（Salesforce/HubSpot）はあるが建設特化はない |
| 自社利用 | **即日利用可能** |
| 収益モデル | 月額9,800円〜 |
| 開発量 | MVP 4〜5画面。3〜4週間 |

**なぜあなた:** 営業のプロセスを自分で設計・実行している。
**リスク:** CRMは「使い続けてもらう」のが難しい。入力が面倒で放置されがち。

### ④ 安全書類AI — グリーンファイル自動生成

```
「職人情報を一度登録すれば、現場ごとの安全書類が自動で出る」
```

| 項目 | 内容 |
|------|------|
| 解決する課題 | 現場ごとに毎回同じような書類を手作業で作成 |
| コア機能 | 職人台帳 → 現場選択 → 安全書類一括生成（作業員名簿・新規入場者教育等） |

| CCUS連携 | 将来的にCCUS APIと連携すれば差別化 |
| 収益モデル | 月額3,980円〜 |
| 開発量 | MVP 3〜4画面。3週間 |

**なぜあなた:** 人材会社として毎回安全書類を出す側。何が必要か熟知。
**リスク:** グリーンサイトとの連携を求められる可能性。

## 推奨: ① 人工見積AI から始める

### 理由

1. **競合ゼロ** — 建設人材会社向けの見積ツールは市場に存在しない
2. **自分が最初のユーザー** — 明日から使える
3. **AI活用が自然** — 過去実績からの単価提案は Claude API の得意分野
4. **法規制が追い風** — インボイス対応・CCUS単価連携のニーズが今後増える
5. **外販の営業が簡単** — 「うちで使ってるんですけど」で同業に見せるだけ
6. **既存コードベース流用可能** — Next.js + Supabase + Claude API + Stripe

### MVP開発ロードマップ

```
Week 1:  単価マスタ + 案件登録画面
Week 2:  人工計算エンジン + 粗利シミュレーション
Week 3:  見積書PDF出力 + AI単価提案
Week 4:  自社で実運用開始
Week 5〜: フィードバック → 改善 → 同業にデモ
```

### 将来の拡張パス（単機能→統合ツールへ自然に育つ）

```
人工見積AI（今ここ）
  ↓ 受注したら配置が必要
配置ボード追加（案⑤を統合）
  ↓ 配置したら安全書類が必要

建設人材会社の業務OS
```

**1つのツールから始めて、自然に機能が広がっていく設計。** プラットフォームではなく、あくまで「ツールの積み重ね」。
